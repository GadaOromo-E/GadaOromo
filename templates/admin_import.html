File rules (English-only list):
• TXT: one English word per line
• CSV: header english (recommended) or first column is used
• XLSX: Column A = English (first row may be header “English”)
• Empty rows are ignored, duplicates are skipped, and rows over 200 are skipped with summary counts.

Important: This import works only if the server has GOOGLE_TRANSLATE_API_KEY set. If the provider fails on some rows, import still completes with partial success.
